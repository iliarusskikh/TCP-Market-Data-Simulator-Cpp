TCP Market Data Simulator · Look-up notes

Theory { Concepts & decisions }

Quick look-ups for concepts and design choices in the finished project — fixed-size binary ticks, single-threaded poll(), heartbeats, no order flow. Not a build tutorial.

01

Reading order

By dependency — each note assumes the ones above it.

  1. foundation
    Sockets & TCP

    Why TCP, Berkeley lifecycle, byte streams ⇒ framing, SO_REUSEADDR. Maps to src/server.cpp and src/client.cpp.
  2. wire
    Binary Protocol

    Fixed-size TICK / HEARTBEAT, packing, endianness, partial reads. See protocol.hpp and recv_feed.
  3. wire · I/O
    Socket Options & Nagle

    TCP_NODELAY on data sockets; buffer sizes left at OS defaults. See socket_opts.hpp.
  4. ownership
    RAII

    SocketGuard for every fd; ClientSession composes with Rule of Zero.
  5. I/O
    Non-Blocking I/O & poll()

    Single-thread poll() loop vs threads or epoll. How the server multiplexes clients.
  6. feed
    Market Data Ticks

    Scaled integer prices, random walk, round-robin broadcast. See tick_generator.hpp.
  7. liveness
    Heartbeat & Reconnect

    App HEARTBEAT, any-message last_rx, client backoff reconnect.
  8. stats
    Latency Measurement

    Inter-arrival p50/p99 via LatencyStats — not RTT or one-way wire delay.
